# oh-my-zsh-custom
My custom themes and plugins for oh-my-zsh

When setting up a new computer, clone the custom repository directly into Oh-My-Zsh's custom directory path:
```
# If ~/.oh-my-zsh/custom already exists, back it up or remove it first
rm -rf ~/.oh-my-zsh/custom
git clone https://github.com ~/.oh-my-zsh/custom
```
